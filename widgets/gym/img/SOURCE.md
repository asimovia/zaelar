# Exercise pictures

The `.jpg` files in this folder are the first picture (`0.jpg`) of the matching exercise in
[yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db) (`exercises/<id>/0.jpg`), resized to 320 px wide.
That repository is released under **The Unlicense** (public domain dedication) — its text is `LICENSE.md` next to this
file. The mapping from the widget's exercise keys to these files is `../exercises.json` (`image`).

23 files, ~335 KB in total.
